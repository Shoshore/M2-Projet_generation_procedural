# Aim of the project
Our aim is to re-implement the paper `Sparse representation of terrains for procedural modeling`, published in **2016** and made by: Eric Guérin, Julie Digne, Eric Galin, Adrien Peytavie.

We are going to implement it using **C++** and **OpenGL**.

# How to execute the code 

mkdir build \
cd build \
cmake .. \
cd .. \
cmake --build build \
./sparce
